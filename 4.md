Here is an automated installation and setup script tailored for Arch Linux to clone and deploy **Hack The Clown's** dotfiles setup (i3-wm, Polybar, Rofi, Atuin, Ranger, Picom, Kitty/Alacritty, Nerd Fonts, and CLI tools).

---

### Installation Script (`install.sh`)

Save the script below as `install.sh`, make it executable, and run it:

```bash
#!/usr/bin/env bash
# ==============================================================================
# Arch Linux Setup Script for hacktheclown/arch-clown-dotfiles
# ==============================================================================

set -e

DOTFILES_REPO="https://github.com/hacktheclown/arch-clown-dotfiles.git"
CLONE_DIR="$HOME/.dotfiles-clown"
BACKUP_DIR="$HOME/.config-backup-$(date +%Y%m%d_%H%M%S)"

echo "=== [1/6] Updating System Repositories ==="
sudo pacman -Syu --noconfirm

echo "=== [2/6] Installing Core X11, WM & Desktop Components ==="
sudo pacman -S --needed --noconfirm \
    base-devel git curl wget \
    xorg-server xorg-xinit xorg-xrandr xorg-xrdb xorg-xsetroot \
    i3-wm polybar rofi picom feh dunst \
    kitty alacritty zsh tmux \
    ranger neovim vim \
    htop btop bat eza ripgrep fzf \
    xclip maim flameshot \
    ttf-font-awesome noto-fonts noto-fonts-emoji \
    pulseaudio-alsa pavucontrol pamixer

echo "=== [3/6] Installing AUR Helper (yay) if Missing ==="
if ! command -v yay &> /dev/null; then
    echo "Installing yay..."
    TEMP_DIR=$(mktemp -d)
    git clone https://aur.archlinux.org/yay-bin.git "$TEMP_DIR/yay-bin"
    (cd "$TEMP_DIR/yay-bin" && makepkg -si --noconfirm)
    rm -rf "$TEMP_DIR"
else
    echo "yay is already installed."
fi

echo "=== [4/6] Installing AUR Packages (Atuin, Fonts, Utilities) ==="
yay -S --needed --noconfirm \
    atuin \
    ttf-jetbrains-mono-nerd \
    ttf-meslo-nerd-font-powerlevel10k \
    betterlockscreen \
    zsh-autosuggestions \
    zsh-syntax-highlighting

echo "=== [5/6] Cloning Repository and Backing Up Existing Configs ==="
if [ -d "$CLONE_DIR" ]; then
    echo "Updating existing dotfiles repo in $CLONE_DIR..."
    git -C "$CLONE_DIR" pull
else
    git clone "$DOTFILES_REPO" "$CLONE_DIR"
fi

mkdir -p "$BACKUP_DIR"
mkdir -p "$HOME/.config"

# Config folders to copy/link if present in repository
CONFIG_TARGETS=("i3" "polybar" "rofi" "picom" "kitty" "alacritty" "ranger" "dunst" "atuin" "tmux")

for item in "${CONFIG_TARGETS[@]}"; do
    if [ -d "$CLONE_DIR/.config/$item" ]; then
        if [ -d "$HOME/.config/$item" ]; then
            echo "Backing up ~/.config/$item -> $BACKUP_DIR/"
            mv "$HOME/.config/$item" "$BACKUP_DIR/"
        fi
        echo "Linking ~/.config/$item"
        ln -sf "$CLONE_DIR/.config/$item" "$HOME/.config/$item"
    elif [ -d "$CLONE_DIR/$item" ]; then
        if [ -d "$HOME/.config/$item" ]; then
            echo "Backing up ~/.config/$item -> $BACKUP_DIR/"
            mv "$HOME/.config/$item" "$BACKUP_DIR/"
        fi
        echo "Linking ~/.config/$item"
        ln -sf "$CLONE_DIR/$item" "$HOME/.config/$item"
    fi
done

# Check and deploy root dotfiles (.zshrc, .Xresources, .tmux.conf, etc.)
DOT_FILES=(".zshrc" ".Xresources" ".tmux.conf" ".xinitrc" ".profile")
for file in "${DOT_FILES[@]}"; do
    if [ -f "$CLONE_DIR/$file" ]; then
        if [ -f "$HOME/$file" ]; then
            echo "Backing up ~/$file -> $BACKUP_DIR/"
            mv "$HOME/$file" "$BACKUP_DIR/"
        fi
        echo "Linking ~/$file"
        ln -sf "$CLONE_DIR/$file" "$HOME/$file"
    fi
done

# Copy any wallpapers or scripts directories if present
if [ -d "$CLONE_DIR/wallpapers" ] || [ -d "$CLONE_DIR/wallpaper" ] || [ -d "$CLONE_DIR/scripts" ]; then
    mkdir -p "$HOME/Pictures/wallpapers"
    cp -r "$CLONE_DIR"/wallpapers/* "$HOME/Pictures/wallpapers/" 2>/dev/null || true
    cp -r "$CLONE_DIR"/wallpaper/* "$HOME/Pictures/wallpapers/" 2>/dev/null || true
    chmod +x "$CLONE_DIR"/scripts/* 2>/dev/null || true
fi

echo "=== [6/6] Finalizing Setup ==="
# Reload Xresources if X is running
xrdb -merge "$HOME/.Xresources" 2>/dev/null || true

# Set up Atuin shell history sync/daemon
if command -v atuin &> /dev/null; then
    echo "Atuin installed. (Run 'atuin register' or 'atuin login' if you have an account)"
fi

echo ""
echo "=========================================================="
echo " Installation Complete!"
echo " - Your previous configurations are backed up in: $BACKUP_DIR"
echo " - Log out or run 'exec i3' / 'startx' to launch the setup."
echo "=========================================================="

```

---

### How to Run

1. **Create the file:**
```bash
nano install.sh

```


2. **Paste the code above**, save, and exit (`Ctrl + O`, `Enter`, `Ctrl + X`).
3. **Make it executable and execute:**
```bash
chmod +x install.sh
./install.sh

```
