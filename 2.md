install_nerd_font() {

    local font_name="$1"
    local url="$2"
    local archive="/tmp/${font_name}.zip"

    if fc-list | grep -qi "$font_name"; then

        success "$font_name already installed."

        --silent \

        -o "$archive"

        -d "$FONT_DIR" \
        >/dev/null

    rm -f "$archive"

    success "$font_name installed."

}

```

Paste the script, then:

```

**Don't run it with `sudo ./install.sh`.** The script uses `sudo` only for the operations that actually require root privileges.

One particularly important fix is the `/home/changeme` issue: the repository's current i3 config really does contain hard-coded paths such as `/home/changeme/.config/i3/scripts/lock`, `/home/changeme/Pictures/wallpaper.jpg`, and the Polybar configuration path.  The updated installer automatically changes those to your actual home directory.

It also changes the repository's original `terminator` binding to **Alacritty**, while retaining the rest of the theme/configuration. The repo officially lists Terminator as its original terminal. ([GitHub][1])

**One caveat:** if your goal is to reproduce the YouTube setup *exactly*, some repository settings are hardware-specific—the author notes that the configuration was developed inside VMware and recommends checking `changeme` and `HTC_NOTE` entries.
